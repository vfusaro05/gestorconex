Política de segurança da informação e proteção de dados do Gestor Conex. Para saber quais dados coletamos e seus direitos pela LGPD, veja a Política de privacidade.

1. Purpose and scope

This policy defines how Gestor Conex protects the confidentiality, integrity and availability of customer data, including data obtained from marketplace integrations (Mercado Livre, Amazon, Magalu, Shopee, TikTok Shop and VendasConex). It applies to all systems, people and providers that process Gestor Conex data, and complements our public Privacy Policy, which follows the Brazilian General Data Protection Law (LGPD, Law 13.709/2018).

2. Roles and responsibilities

  • Founder / Security owner / DPO: approves this policy, controls all production access, handles data subject requests and leads incident response. Contact: suporte@gestorconex.com.br (security reports: apps@gestorconex.com.br).
  • Service providers (cloud hosting, payment processors, e-mail delivery): selected for their security practices and used only for their contracted purpose.

3. Data classification and handling

ClassExamplesProtection
SecretMarketplace access/refresh tokens, API keys, password hashesEncrypted at rest with AES-256-GCM (application-level key held only in the hosting secret store); never logged or displayed; passwords stored only as salted bcrypt hashes.
ConfidentialBusiness data entered by users (sales, expenses, products)End-to-end encrypted on the user's device before upload; Gestor Conex cannot read it.
InternalMarketplace order data (date, items, amounts, fees, shipping, taxes)Stored in a private database; visible only to the owning company account. No buyer names, addresses or contact details are stored.
PublicWebsite, documentationIntegrity controls only.

Data minimization: marketplace integrations are read-only and request only the scopes needed to read orders, financial settlements and shop authorization.

4. Access control (least privilege)

  • Production systems (hosting, database, code repository, marketplace developer consoles) are accessible only to the founder.
  • Multi-factor authentication is required on all administrative accounts; strong unique passwords are kept in a password manager.
  • Each customer can access only the data of their own company account; this is enforced server-side on every request (authenticated sessions with signed tokens).
  • Secrets are stored only in the hosting provider's secret store, never in source code; access is removed immediately when no longer needed.

5. Network and infrastructure security

  • All traffic uses HTTPS/TLS. The database runs on a private network and is reachable only by the API service, not from the internet.
  • The API applies rate limiting, temporary lockout after repeated failed logins, and bot protection (Cloudflare Turnstile) on website sign-up and login.
  • Hosting is on managed cloud infrastructure whose providers patch the underlying systems and provide DDoS protection and monitoring.

6. Endpoint security and daily operations

  • Company computers run up-to-date operating systems with Microsoft Defender Antivirus (real-time protection) enabled.
  • Screen lock on inactivity, disk-level device protection, and a clean-desk practice for any printed material.

7. Vulnerability and change management

  • Third-party dependencies are scanned for known vulnerabilities (GitHub Dependabot, npm audit); high and critical issues are fixed within 7 days, others in the next release.
  • Changes are version-controlled, tested with automated tests before deployment, and can be rolled back.

8. Incident response

  1. Detect and report: anyone may report a suspected incident to apps@gestorconex.com.br.
  2. Contain: the founder revokes or rotates affected credentials and tokens and isolates affected systems.
  3. Investigate and log: scope, data affected, root cause and timeline are recorded.
  4. Notify: when personal data is involved, affected customers and sellers, the relevant marketplace (e.g., TikTok Shop, Shopee) and the ANPD (Brazilian data protection authority) are notified without undue delay and within 72 hours.
  5. Recover and improve: restore service, apply corrective actions and review this policy.

9. Data retention, deletion and data subject rights

  • Users can export and delete their data in the app (My account → Privacy and data). Disconnecting a marketplace shop immediately deletes its tokens and order data.
  • Account deletion removes all data within 30 days, including backups, except payment and tax records that Brazilian law requires us to keep.
  • Requests from users, sellers or marketplaces to access, correct or delete data are answered within 15 days via suporte@gestorconex.com.br.

10. Data location and providers

Application and database are hosted on Railway (managed cloud, United States); the static website is served by Cloudflare. Payments are processed by Mercado Pago, Apple and Google; card data is never received or stored by Gestor Conex. International transfers follow LGPD article 33.

11. Review

This policy is reviewed at least once a year and whenever there is a significant change to systems, providers or data flows.
